1

Download the Excel template

The template is pre-filled with the course names available in {{ department.name }} (see the Valid Courses sheet). It also lists the semesters that belong to each course. Use it as-is — do not rename or reorder the columns.

Download Template
2

Fill in the student rows

Required columns: full_name, admission_number, course_name, exam_type.

exam_type must be knec or internal.
Optional columns: module (e.g. MODULE 1), semester (must match a semester of that course), phone_number, username, password.
If semester is blank, the student is placed into the course's current semester. If username is blank, it's generated from the admission number; if password is blank, it defaults to the admission number.

3

Upload the filled file

You will see a preview of valid rows and any errors before anything is written to the database.

Back to Students
What gets checked before saving:
  • Every row has a full_name and admission_number.
  • The admission number is unique in the whole system and inside the file.
  • The course_name belongs to {{ department.name }}.
  • If semester is filled, it matches a semester of that course.
  • exam_type is either knec or internal.
Rows that fail any check are shown as errors and are not imported.
